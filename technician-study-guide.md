# Technician Class License — Concept Reference Catalog

A study companion for the **2022–2026 NCVEC Technician (FCC Element 2) question pool**.

The official question pool lists 411 questions and their correct answers, but it does not *teach* anything — it assumes you either already understand the material or will memorize the answers. This catalog fills that gap.

**The exam is 35 questions** — one drawn from each of the 35 groups. Pass mark is 26 correct (74%).

## How to use this

1. Read a subelement page top to bottom — concepts first.
2. Open the official pool alongside it and try the group's questions cold.
3. Use the per-question map only to check *why*, not to memorize *what*.

## Sources
